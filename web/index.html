Private FPS Pro Geode Mod

Geometry Dash · Android · Geode SDK 5.5.3
This project is a native C++ mod for Geometry Dash on Android, built with the Geode SDK. It is not a web application — it compiles to a .geode package that is sideloaded into the game on a phone.

Build (locally with Geode CLI)

The Geode SDK and Android NDK toolchain are required. Install the Geode CLI, then:

export GEODE_SDK=/path/to/geode-sdk
geode sdk install-binaries
geode build -p android64

Or use the included GitHub Actions workflow at .github/workflows/build.yml which runs geode-sdk/build-geode-mod and uploads a .geode artifact.

Install on Device

  1. Install Geometry Dash 2.2 and the Geode loader on Android.
  2. Copy the produced fling.private-pro.geode file into the Geode mods folder.
  3. Launch GD, pause any level, and tap the hub icon to open the mod menu.
